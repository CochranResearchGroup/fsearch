## Confinement evidence

Current WSL kernel: 6.6.87.2-microsoft-standard-WSL2, x86_64. Landlock version syscall reports ABI 3. Landlock does not mediate stat-family calls; it cannot alone satisfy the metadata boundary. Every descent must use openat2 with RESOLVE_BENEATH, RESOLVE_NO_SYMLINKS and RESOLVE_NO_XDEV before descriptor metadata. O_PATH must not be combined with O_NOFOLLOW, because that combination can return a symlink descriptor rather than reject it. The scanner is trusted code using a fixed resolution contract; do not claim arbitrary malicious native-code confinement.

Primary sources: https://docs.kernel.org/userspace-api/landlock.html and https://man7.org/linux/man-pages/man2/openat2.2.html. Mount/symlink rejection does not prove disk health. Failed work never authorizes replacement or retry. Fixture errors use injected adapters rather than degraded user mounts.
